# CSI 3680 Lab 5

Read [CSI3680-Lab5-F2026.pdf](CSI3680-Lab5-F2026.pdf) for the questions.

## Setup

Open a terminal in this folder and install the dependencies.

```bash
python -m pip install -r requirements.txt
```

Use `python3` if that is your Python command.

Q1 needs Google Chrome installed locally. Initial driver setup may need Internet access.

## Run the scripts

Complete the four starter scripts, then run each from this folder.

```bash
python q1_scrape_events.py > q1_output.txt
python q2_weather_to_csv.py
python q3_excel_to_csv.py
python q4_name_cards.py
```

## Input files

The weather data and campus events are fictional classroom examples.

The supplied `card_font.ttf` is Overpass. See [FONT_LICENSE.txt](FONT_LICENSE.txt).
